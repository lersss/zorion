| # | Решение |

| 1 | **14 форм поверхности**: скалы, пески, кратеры, лавовые поля, вулканические поля, ледники, мёрзлые газы, океаны, озёра/реки, луга/степи, леса, джунгли, болота, коралловые рифы. |
| 2 | **17 типов недр** (один слой, без глубины), включая «пустую породу». |
| 3 | Композиция: **1–5 типов** на планету, в процентах. |
| 4 | Правило UI: **нулевые значения в карточке не показываются**. |
| 5 | Модель добычи: поверхность — игрок (мини-игра) или NPC; недра — **только завод**. |
| 6 | Ресурсы попадают **к владельцу** (игрок/фракция), не в общий пул. |
| 7 | Поверхность и недра **могут давать одинаковые ресурсы** (железо — и в россыпях, и в жилах). |
| 8 | **Матрица совместимости** форм/типов (N×N, симметричная). |
| 9 | Матрица хранится **в БД**, редактируется через **новую вкладку «Совместимость»** в админке. |
| 10 | Дефолты матрицы — в `config/compatibility_defaults.json`. |
| 11 | **Атмосфера** — отдельный источник ресурсов (экстрактор, неистощаемо). |

Полные формулировки — в `docs/gamedesign.md` (нужно дополнить разделы 4, 5, 6.10, 14).
