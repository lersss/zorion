# Контекст проекта Zorion

**Последнее обновление:** 2026-09-09

## О проекте
Zorion — MMO-песочница с живым самоподдерживающимся миром. Игрок — «серый кардинал», влияющий на мир через контракты. Архитектура универсальна (космос, улей, фэнтези). Мир существует 24/7, NPC-фракции сами создают контракты, воюют, торгуют, колонизируют.

## Геймдизайн (основа)
- **Контракты** — единственный способ влияния на мир. Генерируются NPC-фракциями и игроками.
- **Миры** — звёздные системы с планетами. Генерируются кластерным алгоритмом (Пуассона). 1000 миров по умолчанию.
- **Фракции** — правительства, корпорации, культы. Управляют мирами, принимают решения о войне, колонизации, производстве.
- **Экономика** — 60 товаров (20 категорий), производство через заводы, качество товаров, ресурсы с числовыми свойствами.
- **Перемещение** — между мирами через карту, время в пути зависит от расстояния.
- **Репутация** — меняется в зависимости от действий игрока.

## Что уже реализовано (завершённые задачи)
1. **Круглая карта галактики** — миры генерируются внутри круга (равномерное распределение по площади).  
   - Изменены `galaxy.go`, `poisson.go`, `admin_universe.go`.
2. **Генерация имён** — унифицирована на латиницу, расширена в 2+ раза (120+ префиксов, 60+ корней, 40+ суффиксов).
3. **Батчинг для планет** — ускорена вставка планет, поселений, заводов, товаров и ресурсов в БД.
4. **Убрана добивка без проверки** — миры теперь не накладываются; если не хватает места, генерируется меньше миров с предупреждением.
5. **Проверка глобального круга** — точки кластеров проверяются на попадание в круг при добавлении; масштабирование убрано.
6. **Модальное окно с системой** — при клике на мир открывается окно с визуализацией звезды и планет (Canvas + таблица). Реализованы: адаптивные орбиты, зум, панорамирование, мини-карта, ховер и подсветка объектов.
7. **Курсор и подсветка на карте** — курсор `crosshair` по умолчанию, `pointer` при наведении на мир; полупрозрачная подсветка мира.

## Изменённые файлы (кратко)
- `internal/generator/galaxy/galaxy.go` – новая структура Config, generateWorld (без масштабирования).
- `internal/generator/galaxy/poisson.go` – круговая генерация, проверка глобального круга, убрана добивка.
- `internal/handlers/admin_universe.go` – адаптирован под новый генератор с сохранением в БД.
- `internal/names/names.go` – расширенные списки слогов, единый латинский стиль.
- `internal/generator/planet/generator.go` – батчинг с транзакциями, схема `public`.
- `web/static/js/map/render.js` – размер звёзд по спектру, подсветка при ховере.
- `web/static/js/map/events.js` – обработка ховера, курсор `crosshair`/`pointer`.
- `web/static/js/modal.js` – модалка с системой, орбиты, зум, мини-карта, ховер.
