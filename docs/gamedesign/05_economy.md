## 5.1. Ресурсы

### 5.1.1. 6 категорий

| Категория | Иконка | Назначение |
|-----------|--------|------------|
| Минералы | 🪨 | Металлы, стекло, инструменты |
| Органика | 🌿 | Пища, ткани, лекарства |
| Редкие | ⭐ | Детали, электроника, оружие |
| Топливо | 🔥 | Энергия для заводов, транспорт |
| Вода | 💧 | Питьё, орошение, химия |
| Газы | 💨 | Удобрения, химия, топливо |

### 5.1.2. 9 числовых свойств (0–100)

1. **Твёрдость** — устойчивость к механическому воздействию.
2. **Эластичность** — способность возвращать форму.
3. **Проводимость** — электрическая и тепловая.
4. **Термостойкость** — устойчивость к нагреву.
5. **Химическая активность** — склонность к реакциям.
6. **Плотность** — масса на единицу объёма.
7. **Биосовместимость** — совместимость с жизнью.
8. **Энергоёмкость** — энергия на единицу массы.
9. **Летучесть** — склонность к испарению.

### 5.1.3. Подкатегории

У каждого ресурса есть подкатегория: «железная руда», «нефть», «аммиак».
Используется в рецептах, фильтрах, аналитике. В основном UI скрыта (или в тултипе).

### 5.1.4. Отображение в UI

Рядом с названием ресурса — иконка категории.

Примеры: 🪨 Атрокс, 🔥 Бролин, 💨 Зорнит.

При наведении на иконку — тултип с названием категории.

Названия генерируются по слогам (уникальные для каждого мира / партии). Кириллица + латинская транскрипция (Атрокс / Atrox).

### 5.1.5. Атмосферные ресурсы

- Добываются специальным заводом — **атмосферным экстрактором**.
- Тип газа зависит от типа атмосферы планеты (аммиак из аммиачной, метан из метановой и т.д.).
- Неистощаемы.
- Требуют энергии и денег на операционные расходы.
- Относятся к категории «Газы».

## 5.2. Товары

### 5.2.1. 20 категорий

Продовольствие, напитки, одежда, стройматериалы, пиломатериалы, металлопрокат, пластик, резина, химикаты, инструменты, станки, электроника, комплектующие, топливо, транспорт, запчасти, медикаменты, медоборудование, оружие, броня.

Каждый товар имеет: имя, категорию, качество (0–100).

### 5.2.2. Идеальные профили

Для каждой категории — 9-мерный вектор целевых свойств (0–100). Хранятся в `internal/recipe/profiles.go`.

Примеры:

| Категория | Вектор |
|-----------|--------|
| Металлопрокат | `{80, 40, 70, 90, 20, 85, 10, 20, 10}` |
| Топливо | `{10, 10, 10, 30, 60, 50, 10, 95, 80}` |
| Медикаменты | `{10, 10, 10, 20, 40, 30, 95, 10, 20}` |

### 5.2.3. Качество товара

1. Среднее по каждому свойству ресурсов в рецепте → вектор из 9 чисел.
2. Сравнение с идеальным профилем через евклидово расстояние:

```
distance = sqrt( sum( (среднее_i - идеал_i)^2 ) )
quality  = 100 - (distance / maxDistance * 100)
```

где `maxDistance = sqrt(9 × 100²) ≈ 300`.

3. Округление до целого.

### 5.2.4. Рецепты

Описывают, какие ресурсы (с какими свойствами) и в каком количестве нужны. Пакет `internal/recipe`. Зафиксированы в коде, но структура позволяет расширять.

## 5.4. Заводы

- Завод производит **один товар** (категория фиксирована при постройке).
- Выбор категории при постройке определяется инициатором:
  1. Дефицит на складах.
  2. Доступность локальных ресурсов.
  3. Стратегические цели фракции.
  4. Диверсификация.
- Завод проверяет наличие ресурсов каждые 10 тиков. Если ресурсов нет — простаивает.
- Переключение категории требует модернизации (время + ресурсы).

**Типы заводов по энергии:**
- **Производители энергии:** солнечные, ветряные, геотермальные, топливные, реакторы.
- **Потребители энергии:** все остальные.

---

## 5.5. Энергия

**Энергия — не ресурс, а отдельная сущность.** Производится одними заводами и потребляется другими на той же планете.

### 5.5.1. Производители

| Тип | Зависимость |
|-----|-------------|
| ☀️ Солнечная | Близость к звезде, ясная атмосфера |
| 💨 Ветряная | Плотная атмосфера |
| 🌋 Геотермальная | Вулканические поля в недрах |
| ⚡ Топливная (ТЭЦ) | На входе топливо 🔥 |
| ☢️ Реактор | На входе редкие ресурсы ⭐ |

### 5.5.2. Планетарный рынок энергии

- Заводы-потребители каждый тик автоматически генерируют **микроконтракты** на энергию.
- Рынок собирает микроконтракты и удовлетворяет их из доступной энергии.
- **Игрок не видит микроконтрактов** — это внутренняя механика.
- Игрок видит: свои станции и их доход, цену энергии на планете.

**Цена:** базовая × множитель дефицита (спрос / предложение).

**Энергобаланс:**
- Производство ≥ потребление → все заводы работают.
- Производство < потребление → часть простаивает (приоритет по инициатору).

---

## 5.6. Операционные расходы

- Каждый завод требует денег **каждый тик** (зарплаты, обслуживание, ремонт).
- Без денег завод не работает, даже если есть сырьё и энергия.
- Уход в минус → завод останавливается до пополнения счёта.
- MVP: единая валюта. Валюты фракций — отложены.

## 5.7. Модель добычи ресурсов

| Источник | Кто добывает | Как | Куда попадает |
|----------|--------------|-----|---------------|
| Поверхность | Игрок | Мини-игра | Хранилище игрока |
| Поверхность | NPC-фракция | Сбор | Хранилище фракции |
| Недра | Завод игрока | Автоматически | Хранилище игрока |
| Недра | Завод фракции | Автоматически | Хранилище фракции |
| Атмосфера | Атмосферный экстрактор | Автоматически | Хранилище владельца |

**Принципы:**
- Ресурсы попадают **к владельцу**, не в общий пул.
- Поверхность и недра могут давать одинаковые ресурсы.
- Уникальные: лес, рыба, кораллы — поверхность; нефть, газ, радиоактивные руды — недра.
- Фракции тоже собирают поверхностные ресурсы → конкуренция за точки.
