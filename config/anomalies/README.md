# Аномалии планет

Библиотека художественных описаний аномалий — редких «нарушений» физики,
которые делают планету уникальной.

## Формат

Один файл на аномалию: `config/anomalies/<code>.json`.
Код совпадает с кодом правила в `internal/audit/planet/`.

```json
{
  "code": "jungles_in_cold",
  "title": "Криоджунгли",
  "icon": "🌿",
  "seeds": [
    "текст 1 (2 абзаца)",
    "текст 2",
    ... 10 всего
  ],
  "tails": [
    "концовка 1 (1 абзац)",
    "концовка 2",
    ... 10 всего
  ]
}
