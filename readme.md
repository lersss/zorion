# Zorion

**Zorion** — это MMO-песочница с живым самоподдерживающимся миром. Игрок управляет агентом (кораблём, пчелой, персонажем) и влияет на развитие мира через выполнение контрактов. Архитектура универсальна и не привязана к конкретному сеттингу (космос, улей, муравейник, фэнтези).

---

## 🚀 Быстрый старт

### Требования
- Go 1.21+
- PostgreSQL 15+
- Redis 7+ (для кеширования и брокера)

### Установка и запуск

```bash
git clone https://github.com/lersss/zorion.git
cd zorion

cp .env.example .env
# Отредактируйте .env, указав DATABASE_URL, REDIS_URL, JWT_SECRET и другие параметры

go mod download
go build -o zorion cmd/server/main.go
./zorion
```

### Обязательные переменные окружения

| Переменная | Что | Пример |
|---|---|---|
| `DATABASE_URL` | Строка подключения к PostgreSQL | `postgres://user:pass@host:5432/zorion` |
| `REDIS_URL` | Строка подключения к Redis | `redis://localhost:6379` |
| `JWT_SECRET` | Ключ подписи JWT (минимум 32 байта) | случайная строка |
| `SERVER_PORT` | Порт HTTP-сервера | `8080` (по умолчанию) |
| `TICK_INTERVAL_SEC` | Интервал тика симуляции, секунды | `3` (по умолчанию) |
| `ADMIN_PASSWORD` | Пароль админки | (по умолчанию `admin123` — **сменить в проде**) |

### Миграции БД

SQL-файлы из папки `migrations/`. Применяются **вручную** через psql/pgAdmin:

```bash
psql "$DATABASE_URL" -f migrations/001_init.sql
psql "$DATABASE_URL" -f migrations/002_users.sql
# ... и так далее, по порядку номеров
```

Актуальный список применённых миграций — в `STATUS.md`.

## 📁 Структура проекта (основные папки)

- `cmd/server/` — точка входа (`main.go`)
- `internal/` — внутренние пакеты:
  - `generator/` — генерация миров, планет, ресурсов, фракций
  - `handlers/` — HTTP-обработчики (админка, API)
  - `repository/` — работа с БД
  - `models/` — структуры данных
  - `names/` — генерация имён
  - `auth/` — JWT, middleware
  - `audit/` — движок аудита планет
  - `travel/` — менеджер полётов
- `migrations/` — SQL-миграции для PostgreSQL
- `config/` — JSON-конфиги (архетипы планет, матрица совместимости, аномалии, описания)
- `web/` — фронтенд (HTML, CSS, JS)
- `docs/` — документация
